## The pitch

<!-- pitch:start -->
**Long UNH** at an as-of price of **$367.08** (2026-09-30). Base-case DCF value **$526.64** (43.5% upside); target range $354.47 to $764.68.

| | Bear | Base | Bull |
|---|---|---|---|
| Stage-1 FCF growth | 7.6% | 13.7% | 19.4% |
| WACC | 8.49% | 7.99% | 7.49% |
| Value per share | $354.47 | $526.64 | $764.68 |
| vs price | -3.4% | 43.5% | 108.3% |

- **What the price implies:** a reverse DCF says the market prices in 6.0% stage-1 FCF growth, against 13.7% in the base case (the median of the stock's rolling 5-year FCF CAGRs).
- **Discount rate:** CAPM with rf 5.3%, 5-year beta 0.41, ERP 8.3%, giving WACC 7.99%. Terminal growth 3.0%, 10-year fade.
- **Backtest** (2017-01-03 to 2026-09-30, walk-forward, out-of-sample, net of 10 bp costs), Sharpe with rf = 0: trend signal 0.29, buy-and-hold 0.49, SPY 0.87.

### Honest risks

- **The call depends on beta.** The 5-year beta of 0.41 gives WACC 7.99% and $526.64. The full-sample beta (0.78) gives WACC 10.55% and **$321.29 (-12.5%)**, below the price. The low recent beta reflects a period when UNH's own news dominated its returns (factor-model R² 0.23).
- **The bear case is below the price** ($354.47, -3.4%): this is a long with downside, not a margin of safety in every scenario.
- **FCF is falling:** $25.7B in FY2023 to $16.1B in FY2025, while base-case growth uses the long-run median.
- **Margins:** operating margin 4.2% in FY2025 vs 8.7% in FY2023. The upside needs a recovery that is not yet in the numbers.
- **Risk and signals trail the market:** max drawdown -61.4% vs -33.7% for SPY since 2014-01-03; both the trend signal and buy-and-hold trail SPY on Sharpe.
<!-- pitch:end -->

## Method

- **Stock selection:** a scored screen of liquid US large-caps on data coverage, peer set, testability and
  recognisability ([`results/screen.json`](results/screen.json)). The first pick, Visa, showed no upside and is archived;
  the pitch moved to the next stock on the shortlist with the same code and assumptions, and Costco was run alongside
  as a comparison. Nothing was tuned to make a long case.
- **Valuation:** two-stage FCF DCF with a linear fade to terminal growth, a reverse DCF (what growth the price implies),
  bear/base/bull scenarios from the stock's own rolling FCF growth history, and a growth × WACC sensitivity grid.
- **Discount rate:** CAPM cost of equity from the 10-year Treasury, a daily beta against SPY over the recent window (the full-sample beta is reported as a sensitivity) and the Ken French
  long-run equity risk premium; cost of debt and tax rate from the 10-K.
- **Factors:** Fama-French five factors plus momentum, Newey-West t-stats, rolling betas.
- **Comps:** EV/EBITDA, P/E and FCF yield against the managed-care peer median.
- **Risk:** volatility, beta, max drawdown, historical VaR and ES.
- **Signal test:** a walk-forward trend filter against buy-and-hold and SPY, out-of-sample and net of costs.

## Data

Frozen as of the pitch date with SHA-256 manifests in `data/raw_UNH/` (and `data/raw/`, `data/raw_COST/`):
Yahoo Finance daily prices, SEC EDGAR XBRL 10-K facts (as first reported, filed on or before the as-of date),
FRED 10-year Treasury yield, and the Ken French data library. Known gaps are listed in the summary and never filled
with estimates.

**SEC User-Agent.** SEC EDGAR asks automated clients for a `"Name email"` User-Agent. The code reads it from the
`SEC_USER_AGENT` environment variable; if that is unset it falls back to the project contact
`Par Bahrae githubproproject@proton.me`. In GitHub Actions the value comes from the `SEC_USER_AGENT` repository secret.
Set your own when you re-fetch: `export SEC_USER_AGENT="Your Name you@example.com"`.

## Reproduce

```bash
git clone https://github.com/ParBproject/stock-pitch && cd stock-pitch
python -m venv .venv && . .venv/bin/activate
pip install -e ".[dev]" && python -m playwright install chromium
make all     # offline: screen, notebooks, summary, deck, PDF, web build, ruff, pytest (needs Node 20+ for the web build)
make data    # optional: re-fetch snapshots (network; changes the results, so review the diff)
```

The web deck deploys by pushing `web/dist` to the `gh-pages` branch. `scripts/shoot_readme.py` regenerates the images above.
